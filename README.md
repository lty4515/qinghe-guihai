## 🌊 这是一个怎样的模型？

归海心理学是一套**跨学科、多角度的心理学场域干涉模型**，从一名 17 岁极端创伤亲历者的真实生命经验出发，整合：

- 🧬 **神经生物学**（HPA 轴断崖、生理限度）
- 🧠 **心理学**（认知解离、防御机制、福格行为模型）
- 🏛️ **社会学**（代际木桩、结构压迫、差序格局）
- 📜 **存在主义哲学与文学**（荒诞、自由、意义重构）

**核心主张**：你不是"该被修复的机器"，而是"需要归海的破船"。系统的问题不该由个体独自承担。

**统合公式**：
```
归海 ≈ (生物宿命场 × 墙镜转化场) ÷ 社会异化场 + 同温微光场 → 放海归船
```

**四大场域**：生物宿命场（生理）/ 墙镜转化场（认知）/ 社会异化场（环境）/ 同温微光场（关系）
**五步罗盘**：停 → 看 → 剥 → 连 → 航
